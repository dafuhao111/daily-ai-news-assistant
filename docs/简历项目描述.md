## 简历替换正文

**每日 AI 新闻助手 Agent | AI Agent 开发工程师　2026.11**

**项目概述：** 面向 AI 信息订阅场景，开发基于用户偏好的新闻简报 Agent，支持 RSS 采集、中文摘要、来源追溯、历史查询与定时邮件投递，完成本机单用户 MVP 验证。

**技术栈：** Python、FastAPI、LangGraph、Function Calling、Pydantic、MySQL、SQLAlchemy、APScheduler、Vue 3

- 基于 LangGraph 构建“模型决策—工具执行—结果回传”循环，由 LLM 自主选择工具、参数、调用顺序及停止时机，并记录工具轨迹用于排障与测试。
- 统一注册 RSS 获取、候选检索、原文读取及本地文件等 8 个工具，实现参数校验、工作目录与命令白名单、SSRF 防护及超时限制，约束工具执行权限。
- 结合 Pydantic 校验结构化简报，限定引用当前任务已获取的新闻材料，由服务端补全来源、原文链接与发布时间，拒绝无证据引用和排除词命中。
- 基于 MySQL 实现累计 Token 预算的原子预留与实际用量结算，超时或用量未知时保留额度；持久化任务、简报与投递状态，区分生成失败和邮件推送失败。
