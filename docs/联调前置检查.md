## 本次模型实测

只向模型提供临时目录中的公开测试文件名，不提供真实新闻、邮箱、数据库配置或本机秘密。模型返回 `list_dir(inputs)`，执行器回传同一调用 ID 的结果，模型最终返回预期文件名。两轮请求报告输入 9,835、输出 39，共 9,874 Token。

此前主入口的一次受限生成请求在 30 秒超时，没有返回调用轨迹或用量，不能据此声称零消耗。除本次主入口和备用入口各一次生成验证外，没有进行额外生成重试，也没有发送邮件。

## 本机秘密配置

`.env`、`secrets/mysql_setup.sql` 和 `config/rss_sources.json` 均不提交 Git。建库 SQL 中含项目随机密码，勿复制到聊天、日志或测试材料。

QQ 邮箱按邮箱页面指引开通 SMTP，授权码写入本机 `.env` 的 `SMTP_PASSWORD`；使用 `smtp.qq.com`、465、`ssl`，完整本人邮箱写入 `SMTP_USERNAME` 与 `SMTP_FROM_EMAIL`。收件地址在正式个人资料中保存。SMTP 授权码与 QQ 登录密码不同。启用每日任务前必须实际收到测试邮件并确认。

用户 API 和日常前端只展示任务及投递状态；工具轨迹继续仅供脱敏开发诊断。阶段 F 的真实到点触发、明确 SMTP 超时和并发重复触发验证仍需补足。
