# 每日 AI 简报：前端交互 Demo

基于 Vue 3 + Vite + JavaScript。仅验证产品页面与交互，不含 FastAPI、LangChain/LangGraph、MySQL、RSS 获取或 SMTP 服务。

## 启动

首次使用或需要按锁文件重新安装依赖时，先停止本项目的开发服务和预览服务：在相应终端按 `Ctrl+C`。确认服务退出后，在项目根目录执行：

```powershell
cd frontend
npm ci
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。建议 Node.js 22.12+ 或 24 LTS。

依赖安装完成后，日常启动只需在 `frontend/` 目录运行 `npm run dev -- --port 5173`，无需每次执行 `npm ci`。

### Windows 安装时提示 EPERM / esbuild.exe 被占用

`npm ci` 会清理并重建 `node_modules`。如果 Vite 开发服务、预览服务或构建仍在运行，Windows 可能不允许删除它们正在使用的 `esbuild.exe`，出现 `EPERM: operation not permitted, unlink ...esbuild.exe`。

先停止本项目的相关服务，再重新执行 `npm ci`；失败的安装可能已清理部分依赖，因此应完成重新安装后再启动。若相关服务由其他终端或工具启动，需要在原启动位置停止，不要直接结束电脑上所有 Node.js 进程。

此类文件占用应先通过停服解决，不必首先尝试管理员权限、删除锁文件或修改依赖版本。

## 可操作范围

- 每日简报：5 条虚构新闻，查看演示原文预览、暂停或启用模拟订阅、模拟测试邮件。
- 身份与订阅：称呼、角色、邮箱、关注话题、关键词、排除词、每日时间及时区；校验、保存、撤销。话题覆盖 AI 与学习教育、体育、生活、工作效率、创作，以及模型、Agent、开源、工程和行业。偏好保存在当前浏览器 localStorage，旧版“大模型进展”会迁移为“大模型与研究”。
- 历史简报：切换 4 个固定示例日期，包含正常、生成失败和空状态。
- 每日简报：启动一次简报演示，只显示简洁的生成中、完成或失败状态；投递失败后可单独重试。

## 演示边界

所有新闻与来源名称均为虚构，发布时间和生成时间为示例；原文使用 example.com 占位链接。原文按钮先显示说明，只有用户主动打开示例链接才访问外站。

Agent 工具轨迹样例仅保留在 `src/data/demo.js` 供开发者和自动测试理解流程，不会渲染给用户。它是预设资料，不是 LLM 决策；不读写宿主机文件，不执行 bash 或任何命令。

模拟邮件从未发送，成功提示不代表真实送达；模拟开关不会创建每日调度。资料与偏好仅保存在浏览器，新闻、任务记录和历史在刷新后恢复示例。建议只填写示例资料，不输入真实密码、Token 或 API Key。

示例时间 08:30 和 Asia/Shanghai 只用于演示，不代表最终订阅设置已确认。真实模型、RSS、邮件与数据库接入均留待后续阶段。

- 未验证屏幕阅读器、真实设备、浏览器缩放、全部浏览器兼容性，以及浅色模式的实际截图；不将这些项目宣称为已通过。
