# 每日 AI 简报：前端交互 Demo

基于 Vue 3 + Vite + JavaScript。仅验证产品页面与交互，不含 FastAPI、LangChain/LangGraph、MySQL、RSS 获取或 SMTP 服务。

## 启动

在项目根目录执行：

```powershell
cd frontend
npm ci
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。建议 Node.js 22.12+ 或 24 LTS。

## 验证

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

## 可操作范围

- 每日简报：5 条虚构新闻，查看演示原文预览、暂停或启用模拟订阅、模拟测试邮件。
- 身份与订阅：称呼、角色、邮箱、话题、关注及排除词、时间与时区；校验、保存、撤销。偏好保存在当前浏览器 localStorage，存储失败会明确提示。
- 历史简报：切换 4 个固定示例日期，包含正常、生成失败和空状态。
- Agent 运行：选择正常、无新闻、新闻获取失败、模型失败或投递失败场景，播放不同的预设事件；投递失败后可只重试发送。

## 演示边界

所有新闻与来源名称均为虚构，发布时间和生成时间为示例；原文使用 example.com 占位链接。原文按钮先显示说明，只有用户主动打开示例链接才访问外站。

所有工具轨迹是预设 UI 数据，不是 LLM 决策，不读写宿主机文件，不执行 bash 或任何命令。此固定播放仅适用于 Demo，不是后续真实 Agent 的实现。

模拟邮件从未发送，成功提示不代表真实送达；模拟开关不会创建每日调度。资料与偏好仅保存在浏览器，新闻、任务记录和历史在刷新后恢复示例。建议只填写示例资料，不输入真实密码、Token 或 API Key。

示例时间 08:30 和 Asia/Shanghai 只用于演示，不代表最终订阅设置已确认。真实模型、RSS、邮件与数据库接入均留待后续阶段。

## 本阶段验证记录

- 3 个测试文件、25 项自动测试通过，覆盖本地保存与失败恢复、表单校验、话题切换、历史空状态、任务失败、重复启动保护、投递重试、弹窗焦点和导航。
- `npm run build` 通过，开发页与生产预览页均返回 HTTP 200；生产预览未出现控制台错误或警告。
- 浏览器验证了表单保存后刷新、错误输入、历史日期切换、模拟任务开始与结束、无新闻、来源失败、投递失败后重试，以及弹窗 Tab 循环、Esc 关闭和焦点恢复。
- 在 320、768、1440px 视口检查每日简报，未发现横向溢出；320px 下还检查了设置、历史和运行页面。已查看系统深色模式实际呈现，并检查浅色与深色关键文字配色对比度。
- 界面静态检查无 error 级发现、无无障碍 warn 级发现。保留的两项提示分别是纯颜色变量文件被误判为缺少焦点样式，以及仅在运行中使用的加载指示动画；全局焦点样式与减少动态效果规则均已定义。
- 未验证屏幕阅读器、真实设备、浏览器缩放、全部浏览器兼容性，以及浅色模式的实际截图；不将这些项目宣称为已通过。
