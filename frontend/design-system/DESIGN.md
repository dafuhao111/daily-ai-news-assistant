# 前端 Demo 界面约定

方向：Quiet Product，以浅暖灰和深绿色构成安静的个人阅读工作台，优先让新闻内容、任务状态和操作反馈清楚可读。

- 使用 Vue 3、Vite、JavaScript、原生 CSS；Lucide 为唯一图标来源。
- 所有颜色与圆角来自 `src/tokens.css`，随系统偏好提供浅色与深色。
- 正文采用系统中文无衬线字体；数字与英文辅助标签采用 Cascadia Code / Consolas。字号层次为 10、11、12、14、16、18、24、32px，阅读内容保持克制密度。
- 间距以 4px 为基础，主要使用 8、12、16、20、24、28、32、40、48px；边框 1px，圆角 6px 和 10px，不使用装饰性阴影。
- 侧栏、主阅读区和辅助信息区有明确层次；窄屏将导航和辅助信息顺序展开。
- 控件不低于 44px，焦点边框清晰；原文预览使用原生 dialog，支持焦点约束、Esc 关闭和焦点恢复。
- 页面切换不做动画；仅控件背景 150ms 过渡与运行状态提示，尊重减少动态效果偏好。
- 新闻、来源、日期、邮件结果和工具轨迹必须标明为模拟；工作区不索取秘密。

不采用：渐变背景、营销大标题、装饰性图表、复杂动效、与 MVP 无关的功能入口。

验证命令：`npm test`、`npm run build`，并进行浏览器交互、键盘与响应式检查。
